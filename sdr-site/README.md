The Netlify site ID is `73c27172-4fd2-4169-9d48-17381238c906`. It is deployed as a separate static site; the parent repository's Netlify build publishes only `public/`, so this directory is not included in the SPECTER Imaging website.

Public feature and Help Center updates should be grounded in `docs/FEATURES.md`, `docs/WHATS-NEW.md`, and `docs/USER-GUIDE.md` from the private `datadrian/specter-sdr` repository. Advertise only complete, working capabilities and run the public terminology and em-dash checks before deployment.
