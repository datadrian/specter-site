Windows installer

The production installer is being prepared. When released, this page will provide the signed SPECTER SDR setup package and its version information.

System requirements

  • Windows 10 or Windows 11, 64-bit
  • One or more RTL-SDR compatible receivers for hardware mode
  • Powered USB hubs recommended for larger arrays
  • Storage appropriate for session audio, spectrum tracks, and reports
  • Internet access for first license activation

First launch

Select USB Hardware, Simulation, or None. Hardware users can run the integrated WinUSB driver diagnosis and installation flow. Simulation provides a complete synthetic two-to-eight receiver training environment.

Read Getting Started and Receiver and Driver Setup before configuring a permanent array.
