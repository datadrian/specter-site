Windows security notice

SPECTER SDR installers are code-signed by Adrian Stucker. Because this publisher certificate is new, Microsoft Defender SmartScreen may temporarily show a warning while Windows builds its reputation.

  1. Download SPECTER SDR only from this official page.
  2. If Windows displays Windows protected your PC, select More info.
  3. Confirm the publisher is Adrian Stucker and the app name matches the installer you downloaded.
  4. If those details are correct, select Run anyway to continue. If the publisher is missing or different, cancel the installation and contact support.

A SmartScreen warning can appear temporarily for software signed with a new certificate. Always verify the publisher before continuing.

System requirements

  • Windows 10 or Windows 11, 64-bit
  • One or more validated RTL-SDR or bladeRF receivers, or a remote rtl_tcp source, for hardware mode
  • Powered USB hub recommended for larger arrays
  • Storage appropriate for session audio, spectrum tracks, IQ captures, and reports
  • Internet access for first license activation and optional updates

First launch

Select USB Hardware, Simulation, or None. Hardware users can run the integrated WinUSB driver diagnosis and installation flow. Simulation provides a clearly labelled two-to-eight receiver training environment.

Read Getting Started and Receiver and Driver Setup before configuring a permanent array.
