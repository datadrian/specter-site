System requirements

  • Windows 10 or Windows 11, 64-bit
  • One or more compatible RTL-SDR receivers for hardware mode
  • Powered USB hub recommended for larger arrays
  • Storage appropriate for session audio, spectrum tracks, IQ captures, and reports
  • Internet access for first license activation and optional updates

First launch

Select USB Hardware, Simulation, or None. Hardware users can run the integrated WinUSB driver diagnosis and installation flow. Simulation provides a clearly labelled two-to-eight receiver training environment.

Read Getting Started and Receiver and Driver Setup before configuring a permanent array.
