Family-aware Windows driver setup

Receiver Setup identifies supported RTL-SDR, LimeSDR, and bladeRF hardware, shows the active Windows driver, and reports whether the installed runtime can open it. Driver requirements vary by family, so follow the detected-device status rather than applying one driver rule to every radio.

  1. Open ARRAY SETUP from the left drawer.
  2. Review the USB Driver Setup panel.
  3. Press INSTALL SDR DRIVER when a compatible interface is not using WinUSB.
  4. Approve Windows elevation, then allow the receiver service to restart and rescan.
Change only the exact supported interface identified by Receiver Setup. Never apply a driver change to unrelated hardware. Review the Supported Radios guide before changing drivers for LimeSDR or bladeRF.

Manual Zadig fallback

Use OPEN OFFICIAL ZADIG if automatic installation cannot bind a receiver. In Zadig, enable List All Devices, select the RTL2832U Interface 0 device, choose WinUSB, then install or replace the driver.

Stable receiver identity

Many inexpensive dongles ship with the same serial, commonly 00000001. Duplicate serials can prevent every connected receiver from appearing and make stable slot restoration impossible.

Program a unique serial with only one dongle connected at a time:

rtl_eeprom -s 00000002

Repeat with a different serial for each receiver. SPECTER SDR can then restore names, slots, tuning, gain, antenna roles, bearings, and saved configurations consistently.

USB power and bandwidth

  • Use a powered USB 3 hub for larger arrays.
  • Split receivers across independent USB controllers when practical.
  • Use matched antennas and feed lines for meaningful amplitude comparison.
  • Test unplug, replug, and restart behavior before field deployment.
