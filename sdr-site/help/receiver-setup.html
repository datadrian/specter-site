Family-aware Windows driver setup

Receiver Setup identifies supported RTL-SDR, LimeSDR, and bladeRF hardware, shows the active Windows driver, and reports whether the installed runtime can open it. Driver requirements vary by family, so follow the detected-device status rather than applying one driver rule to every radio.

  1. Open ARRAY SETUP from the left drawer.
  2. Review the USB Driver Setup panel.
  3. Press INSTALL SDR DRIVER when a compatible interface is not using WinUSB.
  4. Approve Windows elevation, then allow the receiver service to restart and rescan.
Change only the exact supported interface identified by Receiver Setup. Never apply a driver change to unrelated hardware. Review the Supported Radios guide before changing drivers for LimeSDR or bladeRF.

Manual Zadig fallback

Use OPEN OFFICIAL ZADIG if automatic installation cannot bind a receiver. In Zadig, enable List All Devices, select the RTL2832U Interface 0 device, choose WinUSB, then install or replace the driver.

Stable receiver identity

Factory RTL-SDR serials such as 00000001 are shared by many dongles. With duplicate serials, a saved name can follow USB enumeration order rather than one physical radio. Keep each dongle's hardware serial unique for a dependable array.

Give a factory-serial RTL dongle its own identity (v1.7.39+)

  1. Identify the intended dongle. If you cannot distinguish identical units, connect and configure one at a time.
  2. Select it, open IDENTITY, and choose GIVE UNIQUE SERIAL. The option is for supported local, non-simulated factory-serial RTL devices, not tinySA, remote rtl_tcp, or every radio family.
  3. Use the suggested unused serial or enter 1 to 14 letters, digits, underscores, or hyphens. Choose a different value for every dongle.
  4. Save and wait for the app to verify the EEPROM write. Do not unplug or interrupt power during the write.
  5. After success, unplug and replug the dongle as prompted. Confirm its name, antenna, bearing, and saved settings follow the physical receiver.

The operation changes the serial descriptor and preserves manufacturer and product descriptors, including the product identity used by RTL-SDR Blog V4. It is a persistent hardware change, not merely a display nickname. A failed verification must be treated as a failed write, not success.

On older versions, an experienced operator can use the external rtl_eeprom utility with only the intended dongle attached. Prefer the application's guided, verified workflow where available. See version availability.

Name a newly connected receiver

From v1.7.39, a previously unconfigured receiver connected after setup opens a dialog for its name, antenna role, and bearing. A supported factory-serial RTL dongle also offers a unique serial. Choose LATER to use the IDENTITY drawer afterward. While Array Setup is open, the wizard handles naming instead of opening a competing dialog.

USB power and bandwidth

  • Use a powered USB 3 hub for larger arrays.
  • Split receivers across independent USB controllers when practical.
  • Use matched antennas and feed lines for meaningful amplitude comparison.
  • Test unplug, replug, and restart behavior before field deployment.

Sequential hot-plug setup

For several identical radios, connect and configure one receiver at a time. Name it, assign its slot and antenna role, save it, then connect the next radio. The wizard preserves stable order and existing metadata while each new receiver is identified.

  1. Disconnect the unconfigured receivers.
  2. Connect the first radio and wait for it to appear.
  3. Assign a unique name, slot, role, and bearing, then save.
  4. Connect the next radio and repeat until the array is complete.
  5. Select FINISH only after the final deduplicated roster is visible.
