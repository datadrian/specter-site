Operate the complete workstation

Use these guides from first receiver connection through array scanning, raw IQ capture, remote radios, live decoding, recording, and network output.

01

Getting started

Install, choose hardware or simulation, build the first array, and confirm live data.

 02

Receiver setup

Bind WinUSB safely, assign stable receiver identities, and plan multi-radio USB capacity.

 03

Workstation controls

Tune, link, sweep, focus, combine, and display every receiver from one workspace.

 04

Frequency Manager and scanner

Import channel lists, run one-radio or full-array scans, use priority channels, and review hits.

 05

IQ and remote receivers

Capture and replay SigMF baseband or add network radios through rtl_tcp.

 06

Network output and rigctl

Serve ADS-B data, stream audio to Icecast, and expose standard radio control.

 07

Decoder and signal intelligence

Run built-in and supported live-engine decoders, Pattern Hunter, Search Director, and Skywatch.

 08

Array and Rosebud

Map antenna roles and bearings, compare receivers, and annotate a second-screen view.

 09

Recording and alerts

Record synchronized evidence, configure alert classes, review events, and export reports.

 10

ADS-B aircraft

Run 1090 MHz monitoring, operate the map, configure emergency alerts, and enable SBS output.

 11

Imaging integration

Configure the optional local event handoff between two separate applications.

 12

Licensing

Activate a permanent SDR license, bundle key, replacement key, or demo.

 13

Troubleshooting

Resolve receiver, scan, playback, network-output, audio, recording, and activation issues.
