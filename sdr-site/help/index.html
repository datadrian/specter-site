Operate the complete workstation

Use these guides from first receiver connection through array scanning, raw IQ capture, remote radios, live decoding, recording, and network output.

01

Getting started

Install, choose hardware or simulation, build the first array, and confirm live data.

 02

Receiver setup

Detect sources, assign stable identities, set array roles, and validate live frames.

 03

Supported radios

Compare validated RTL-SDR, bladeRF, remote rtl_tcp, and current LimeSDR validation status.

 04

TinySA spectrum analyzers

Add a TinySA as a spectrum-only source, configure sweep controls, record traces, and keep radio-only functions clearly separated.

 05

Workstation controls

Tune, demodulate, scan, focus, combine, and listen to every receiver.

 06

Visualizers and Advanced Display

Configure 2D, 3D, terrain, Rosebud, aggregate, and up-to-six-view displays.

 07

Frequency Manager and scanner

Import channel lists, partition full-array scans, prioritize, hold, and review hits.

 08

IQ and remote receivers

Capture and replay SigMF baseband or add network radios through rtl_tcp.

 09

Network output and rigctl

Serve ADS-B data, stream audio to Icecast, and expose standard radio control.

 10

Decoder Lab

Run 14 guided profiles with built-in validation or supported local engines.

 11

Sensors and radiosondes

Decode compatible 315, 433, 868, and 915 MHz devices with rtl_433 or follow weather balloons with auto_rx.

 12

Research and signal intelligence

Run Pattern Hunter, Search Director, and Skywatch contextual analysis.

 13

Array and Rosebud

Map antenna roles and bearings, compare receivers, and annotate a second-screen view.

 14

Recording and alerts

Record synchronized evidence, configure alert classes, review events, and export reports.

 15

ADS-B aircraft

Run 1090 MHz monitoring, operate the map, configure alerts, and enable SBS output.

 16

Imaging integration

Configure the optional local event handoff between two separate applications.

 17

Licensing

Activate a permanent SDR license, bundle key, replacement key, or demo.

 18

Troubleshooting

Resolve receiver, scan, playback, output, audio, recording, and activation issues.

 19

Channel Activity Watch

Watch a tuned channel, choose responses, and save audio with available pre-roll.

20

Radiation counter and timeline

Connect a GQ GMC counter, read its dedicated strip, and record alongside RF.

21

What's New and versions

Check public-release availability and version-specific changes through the latest source.
