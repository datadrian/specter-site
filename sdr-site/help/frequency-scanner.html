Frequency Manager

Frequency Manager is the searchable channel database in the left drawer. Every entry stores a name, frequency, mode, and optional group. Groups also become channel and priority sources for the scanner.

Save and recall

  1. Tune the selected receiver.
  2. Open FREQUENCY MANAGER.
  3. Enter a name and optional group, then press SAVE CURRENT.
  4. Filter by group or search by name or MHz. Double-click any row to tune it.

Import and export CSV

IMPORT CSV accepts name, frequency, mode, group. A header is optional; MHz or Hz values, commas, semicolons, tabs, and quoted fields are supported. Frequencies are checked against 24-1766 MHz and duplicates are skipped. EXPORT CSV writes the same portable shape.

Start a squelch scan

  1. Open SCANNER below the swept-survey controls.
  2. Choose Range to use Start, End, and Step, or choose a Frequency Manager group.
  3. Set Threshold dB. Start near 12 dB above the floor.
  4. Set Settle ms, 220 ms by default, and Resume after ms, 1500 ms by default.
  5. Optionally choose a priority group and revisit interval.
  6. Press SCAN.

Use the whole array

Enable Use whole array before scanning. Range channels are split into contiguous slices; saved groups are distributed round-robin. Five available radios cover channels roughly five times faster and can hold on five active signals independently. A receiver reserved for dedicated ADS-B is excluded automatically.

The status line identifies the active array count, progress, held frequencies, and receiver names. Every hit remains attributed to the receiver that heard it.

Skip, lock out, and prioritize

  • SKIP: log the partial hit and resume scanning.
  • LOCKOUT: persist the held frequency in the nuisance list with 5 kHz tolerance.
  • Priority group: revisit important saved channels every configured number of scan steps.

Review the hit log

Every completed hit records time, frequency, peak dB above floor, duration, detected CTCSS tone, and receiver. Double-click a hit to tune it immediately.

CTCSS tone detection and squelch

Open FILTER & SIGNAL. Leave CTCSS on Off / detect only to identify any of the 38 standard PL tones on the current NFM signal. Select a specific tone to mute audio unless that tone is present. Detected tones are included in scanner hits.
