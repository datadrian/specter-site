Separate key format

SPECTER SDR keys begin with SSDR. SPECTER Imaging keys begin with SPTR. A key activates only its matching application.

Activate SPECTER SDR

  1. Open Settings, then License.
  2. Enter the purchase email.
  3. Paste the complete SSDR key.
  4. Select Activate License.

Activation binds the key to one computer. The application works offline after activation.

SPECTER Complete bundle

Bundle buyers receive one email containing two keys: one SPTR Imaging key and one SSDR radio key. Activate each inside its matching application.

Replacement keys

If you replace a computer or need recovery, submit a support ticket with the purchase email and original key when available. A replacement preserves the original product type and marks the former record as replaced in the shared license console.

Demo

The demo lasts 30 minutes from first launch, measured as elapsed clock time rather than accumulated usage. Closing the app does not pause or reset it. When it expires, license activation remains available. Use a valid SDR key to continue.
