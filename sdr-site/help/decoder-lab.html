One guided workspace for 14 profiles

Decoder Lab tunes a selected receiver, applies the required mode and channel width, checks antenna fit, and returns traffic to one receiver-tagged feed. Five built-in decoders validate frame or checksum structure. Nine additional profiles guide supported local engines and report the engine's own validated or parsed output.

Run a profile

  1. Open DECODER LAB.
  2. Select the profile, receiver, and lawful regional frequency.
  3. Review the antenna guidance and any mismatch warning.
  4. Install the named local engine if the profile is not built in.
  5. Select START DECODER and watch the receiver-tagged feed.
  6. Select STOP RESTORE to return the radio to its prior state.

Validation language

A frequency match is not a decode. Built-in profiles require valid frame or checksum structure before display. Engine-assisted profiles identify the engine and preserve its reported validation state. Keep raw IQ or session evidence when a result matters.

Sensor and radiosonde workflows have their own frequency, antenna, privacy, and troubleshooting guidance in Sensors and Radiosondes.
