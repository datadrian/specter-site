One packet workspace for the receiver array

Decoder Lab tunes a selected receiver, applies the required mode and bandwidth, checks antenna fit, and returns validated or engine-reported traffic to one receiver-tagged feed. The rest of the array continues operating.

A decoder result is not the same as a frequency match. Built-in decoders validate frame or checksum structure before display, while supported external engines report their own live results.

Where a supported project publishes a suitable Windows build, INSTALL ENGINE downloads from the project's official release, verifies a pinned SHA-256 digest, and installs locally. Nothing downloads until the operator requests it.

Run a decoder

  1. Open DECODER LAB.
  2. Select a profile, receiver, and region-appropriate frequency.
  3. Review the antenna guidance and any mismatch warning.
  4. Install the engine if the profile requires one.
  5. Select START DECODER and watch the live packet feed.
  6. Use STOP & RESTORE to return the receiver to its previous state.

Preserve useful context

Decoder entries retain receiver, frequency, time, source and destination where available, validation state, and a payload summary. For important traffic, preserve the related session or IQ capture and record the antenna and receiver configuration used.

Radio monitoring and publication laws vary by country and service. SPECTER SDR is receive-only. Use decoded information lawfully and do not interfere with licensed users or safety services.
