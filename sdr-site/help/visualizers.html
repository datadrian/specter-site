Build a one-to-six-view display

Open ADVANCED DISPLAY, choose a receiver in each tile, then assign an independent visualization. A tile can follow the live workspace or remain tied to its selected radio. The common timeline keeps all active views aligned during pause, playback, event navigation, and return to live.

  1. Open Advanced Display from the command bar.
  2. Select a layout with one to six tiles.
  3. Choose a receiver and visualization for each tile.
  4. Use PAUSE, PLAY, fixed jump controls, or JUMP TO LIVE across the shared timeline.

GPU and fallback behavior

3D views prefer WebGL2. When Chromium exposes software rendering or blocks a usable GPU context, SPECTER automatically uses its interactive Canvas2D fallback instead of leaving a black tile. Measured FPS appears in the display header.

Direction limit: Direction Compass and Rosebud compare receiver amplitudes. They do not calculate a geographic fix. Use matched antennas, feed lines, gains, rates, and bearings for meaningful comparison.

Annotation and export

Use pen, circle, and arrow tools to mark a live or paused view. Choose color and size, undo or clear marks, save ink, and export a PNG for a report or field note.
