Advanced Display overview

Advanced Display can show one to four simultaneous tiles. Each tile selects its own receiver and visualization, while all tiles share the same live or recorded timeline. Route the window to another display without losing the main receiver workspace.

Detached receiver analysis

Select POP OUT on any receiver card to open a resizable analysis window. The window can switch views live without closing the receiver or interrupting the rest of the array.

ViewWhat it measures or shows
Spectrum + WaterfallAdaptive live spectrum and scrolling history
PersistenceA decaying frequency-by-amplitude density histogram with current trace and max hold
3D TerrainInteractive history geometry viewed from an orbiting camera
Spectrum TunnelThe same measured history from a camera at the leading edge of the terrain
Band OccupancyTime-bucketed activity scored against a displayed threshold above the receiver floor, with observed duty cycle
Direction CompassRelative-amplitude lobes for bearing-assigned receivers, receiver agreement, and an amplitude-weighted resultant
IQ ConstellationComplex raw baseband across the received span, including noise cloud, carrier structure, clipping, and 8-bit quantization
Direction Compass is not geolocation. It requires at least two meaningful bearing-assigned receiver inputs and reports comparative amplitude only. The display labels the result NOT A FIX.

Array-wide views

Rosebud compares receiver sectors, inferred bearing, movement, and timeline context in a radial array display. Aggregate Spectrum stitches ranges partitioned across multiple receivers into one full-range spectrum and waterfall.

Open one to four Advanced Display tiles

  1. Open ADVANCED DISPLAY from the workspace.
  2. Choose the number of view tiles.
  3. Select a receiver and visualization in each tile header.
  4. Set palette, accent, grid, background, contrast, and gamma for the display environment.
  5. Move the window to the intended monitor and maximize it.

Live raw baseband

IQ Constellation requests a low-rate display copy of complex baseband only while that viewer is attached. The receiver and normal spectrum path continue operating. The view represents the whole sampled span, not a single demodulated channel, and labels RTL 8-bit lattice behavior so quantization does not look like invented signal structure.

Rendering behavior

WebGL2 is preferred for accelerated 3D views. Persistence and several analysis displays use efficient canvas rendering, while terrain views have a canvas fallback when a working GPU context is unavailable. Reducing tile count, FFT zoom, or waterfall speed can improve frame rate on older systems.

Choose views to answer a question. Use flat spectrum for exact frequency work, Persistence and Occupancy for intermittent behavior, history and tunnel views for change over time, Direction Compass and Rosebud for receiver comparison, and IQ Constellation for complex baseband structure. A dramatic visualization is not additional evidence by itself.
