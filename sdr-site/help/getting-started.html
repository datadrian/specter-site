Hardware and Windows

SPECTER SDR runs on 64-bit Windows 10 or Windows 11 and supports up to eight RTL2832U-based receivers, including RTL-SDR Blog and NESDR models. A powered USB hub is recommended for larger arrays.

1. Connect receivers and check drivers

Each receiver needs the WinUSB driver on RTL-SDR Interface 0. The first-run Receiver Setup wizard lists every compatible interface and its current driver.

  1. Connect the receivers before launching SPECTER SDR.
  2. Press INSTALL SDR DRIVER only for compatible RTL-SDR interfaces that are not ready.
  3. Approve the Windows administrator prompt.
  4. If the built-in installer cannot finish, use OPEN OFFICIAL ZADIG as the manual fallback.
Do not replace drivers on unrelated USB devices. The built-in installer is allowlisted to compatible RTL-SDR Interface 0 hardware.

2. Choose a receiver source

SourceBehavior
USB HardwareDiscovers and operates connected receivers. Missing hardware is reported honestly.
SimulationRuns two to eight clearly labelled synthetic receivers for training and testing.
NoneOpens the workstation without starting the radio sidecar or loading receiver rows.

3. Build the array

  1. Press AUTO-FIT CONNECTED.
  2. Set each radio's name, array role, and bearing.
  3. Press FINISH SETUP.
  4. Optionally save the complete configuration by name.

Saved configurations include receiver names, positions, tuning, source, DSP, and alert settings.

4. Confirm live operation

The header should show SDR LINK ONLINE and the correct receiver count. Each receiver card should show a changing spectrum, waterfall, signal level, floor level, and measured input frame rate.

Simulation profiles

  • Urban FM Band: busy broadcast spectrum.
  • Quiet Field Baseline: low-noise testing.
  • Indoor Mixed RF: mixed indoor interference.

Simulation produces correlated events across receivers so array comparison can be tested without hardware. It is always explicit and never replaces a failed live radio.

Configure identical radios one at a time

If several receivers share the same factory identity, use the sequential hot-plug workflow in Receiver Setup. Connect, name, assign, and save each radio before plugging in the next one.

New receivers and current-version controls

From v1.7.39, plugging in an unconfigured receiver after setup opens a naming dialog. For factory-serial RTL dongles, use the guided unique serial workflow to keep names attached to physical radios. The installed receiver engine also avoids repeated large temporary-file extraction on launch.

From v1.7.40, try ACTIVITY WATCH on a known channel and configure audible alerts in Settings > Alerts. Check the recording defaults before enabling a watch. Review What's New for v1.7.41-specific changes.
