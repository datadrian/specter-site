Continuous recording

Press RECORD to capture the workspace composite with lossless per-receiver BWF audio and timestamped spectrum data. Name the investigation and add location or session notes when prompted.

FLAG EVENT marks the current point on the session timeline. Stop and resume creates additional segments inside the same investigation.

Event clips

With event clip capture enabled, receiver bursts that qualify under the event rules retain pre-roll and post-roll evidence. Composite Rosebud clips can accompany per-receiver evidence. These video/evidence clips are separate from the activity watch's audio-only WAV recordings.

v1.7.41 behavior: an enabled alert class must match, the receiver's Alerts from this receiver switch and threshold override must permit the event, and a tinySA also requires Spectrum analyzer alerts. If only CRITICAL is enabled, lower-class or unclassified bursts should not generate new event clips. Older versions could save these clips even when no enabled class matched. See version availability.

Popup display preferences, popup cooldown, and hiding lone-burst dialogs are not the same as disabling an alert class. In v1.7.41, otherwise qualifying RF evidence can still be kept without displaying every popup. An update does not delete clips already saved by an older version.

Alert classes

NOTICE, ALERT, and CRITICAL each have an independent label, enable switch, dB-above-floor threshold, and optional band restrictions. Default thresholds are 8, 12, and 20 dB.

Alert cards identify the class, receiver, frequency, level above threshold, and captured spectrum/waterfall evidence. Synchronized views from every receiver are preserved for comparison.

  • Set alert cooldown from 1 to 600 seconds.
  • Choose whether isolated receiver bursts can alert without array confirmation.
  • Enable array correlation when multi-radio confirmation is required.
  • Acknowledge an alert, mute alerts temporarily, or open its review.

Event review

Review opens the saved composite replay, per-radio evidence strip, metadata, and exact session timeline position. Alert severity is visually distinct and remains tied to the stored event.

Library and recovery

LIBRARY lists sessions, event clips, snapshots, and Research findings. Interrupted sessions from a crash or power loss are shown explicitly instead of being hidden. OPEN RECORDINGS opens Documents\SPECTER SDR\.

Reports and export

Generate printable HTML and PDF alert reports containing signal metadata, investigation context, and embedded spectrum and waterfall evidence. Use the timeline range tools to review and export a selected part of a session.

Audible alerts (v1.7.40+)

Open Settings > Alerts > Audible Alerts. New aircraft contact, NOTICE, ALERT, and CRITICAL have separate checkboxes and distinct tones. Checking a sound previews it. These four sounds are off by default; enabling a sound does not enable the corresponding RF alert class or ADS-B monitoring.

When the receiver audio context is running, tones use that output device but bypass the receiver mixer's master-volume control. Otherwise they use the system's default audio output. To silence notifications, turn off their sound switches rather than relying on the receiver master volume. Windows volume and output-device settings still matter.

Channel activity has its own Alert sound switch under Channel Activity Watch. Its defaults differ: the watch is off per receiver, but sound and recording are enabled in its response settings. Read the activity guide.

Check class and receiver permissions

For a new configuration, NOTICE (8 dB) and ALERT (12 dB) begin disabled, while CRITICAL (20 dB) begins enabled. Existing saved settings are retained. The values are excess over the receiver's noise floor, not calibrated absolute field strength. Review optional class band restrictions and each receiver's IDENTITY alert switch and threshold override.
