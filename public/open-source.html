FFmpeg

The Windows installer uses a replaceable shared LGPL build of FFmpeg 8.1 with GPL and nonfree components disabled. Video encoding uses Windows Media Foundation rather than libx264 or libx265. The installer and corresponding public release include exact FFmpeg source and build scripts in the versioned Open Source Components archive.

Installed notices

Settings provides offline access to the third-party notices and source offer. Electron and Chromium notices are installed next to the application executable. Node and Python dependency notices and license files are installed in the application legal directory.

Source request

If a corresponding-source archive becomes unavailable, request a durable copy at support@specter-imaging.com and identify the installed version. The offer remains available for at least three years after the last distribution of the corresponding object code.
