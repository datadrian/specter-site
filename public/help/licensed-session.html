LICENSED SESSION PROGRAM

A hands-off session arc for live venues (licensed producers)

OVERVIEW

Licensed sessions run a silent session program. There is no visible timer, label, or countdown in the UI — by design. It shapes the session underneath so you can run the room.

Demo mode uses fixed demo sensitivity and does not run this program.

HOW A SESSION RUNS

  1. Activate your license in Settings → License.
  2. Start the camera feed — detectors stay off until the feed is confirmed active.
  3. Ramp phase (~25 min): detectors on; face and anomaly sensitivity gradually increase, so more surfaces over time. Body threshold follows your Settings (not ramped).
  4. Dark phase (~10 min): detectors off; the picture dims.
  5. The arc repeats silently.

PRODUCER CONTROLS

  • Manual detector toggles still work, but may conflict with the program's intent.
  • There is a settings option to disable the session program for fully manual operation.
Because the program has no on-screen indicator, judge a session by what you see on the feed and detectors — not by waiting for a banner.
