SPECTER FOR EDITORS

Review the evidence and screen-capture it for the edit

This guide is for the post team. It walks you through installing SPECTER, pointing it at the daily Specter media folder, and using the gallery, 3D depth orbits, EVP audio lab, and the recorded feeds so you can screen-capture clean evidence footage for the show.

Windows only. SPECTER is a Windows desktop application. There is no Mac or Linux build. Run it on a Windows 10/11 machine (a Parallels or Boot Camp Windows install on a Mac works too).

1. DOWNLOAD AND INSTALL

Download SPECTER for Windows

  1. Download and run SPECTER-Setup.exe.
  2. If Windows SmartScreen shows a "Windows protected your PC" prompt, click More info then Run anyway. The app is safe; it is just not code-signed for mass distribution.
  3. Finish the installer and launch SPECTER from the Start menu.

You do not need any sensor, camera, or hardware plugged in to review evidence. Editors run SPECTER purely as a viewer.

2. GET A LICENSE KEY

Browsing saved evidence in the gallery works without a live sensor, but to run the app cleanly without the demo time limit you'll want a license key.

Reach out to the producer for a key. Editors don't buy a license. Message the producer and you'll be issued a SPTR-XXXX-XXXX-XXXX-XXXX key.

Activate it in the app under Settings, License and Help, License. Paste the key and click activate. The app works offline after the first successful activation.

If SPECTER ever shows a DEMO MODE badge with a countdown, that timer only applies to running live sensors. Reviewing the folder of saved evidence in the gallery is not affected. Activating your key removes the badge entirely.

3. THE DAILY Specter FOLDER

Each day's media drop includes a folder named Specter. Inside it you'll find two kinds of evidence:

  • Detections - saved capture events. These live in session_* subfolders. Each detection holds the still image(s), depth data for the 3D orbit, a short clip, EVP audio, and a metadata file with the timecode.
  • Screen recordings - full-length MP4 recordings of the operator's session, the Evidence Wall, or a live sensor feed.

Copy the whole Specter folder somewhere local on your Windows machine. An internal or fast external drive is best; reviewing depth 3D off a slow network share can stutter.

Keep the folder structure intact. Don't rename or move files inside a session_* folder. The gallery reads them by name (for example snapshot.png, snapshot_depth.png, depth_raw.bin, metadata.json).

4. POINT SPECTER AT THE EVIDENCE

Rather than copying files into a hidden system folder, just tell SPECTER where the evidence lives. This is the easiest and safest way:

  1. Open Settings (the gear).
  2. Go to the Recording tab and find DETECTION SAVE FOLDER.
  3. Click Choose and select the Specter folder you copied (or the detections folder inside it, if the day's drop separates them).
  4. Do the same for the SCREEN RECORDING folder if the screen recordings are in a separate subfolder, so the recorded clips are easy to find.
Why this matters: the gallery scans whatever folder is set as the Detection folder for session_* subfolders. Point it at the day's Specter drop and every detection appears automatically.

Next to each folder path there's a reveal control. SPECTER can open the folder in Windows Explorer so you can grab the raw MP4s directly when you need them.

5. THE GALLERY (IMAGES AND DEPTH)

Open the Gallery from the main toolbar (or the right-rail open-gallery button). You'll see every detection from the folder as a grid of thumbnails, grouped by session.

  • Filter and sort - narrow by session, by capture mode, or by intensity, and sort newest or oldest or by intensity. Handy when a day has hundreds of hits.
  • Open a detection - click any thumbnail to open the review view.
  • Layer bar (RGB / DEPTH / THERMAL / 3D) - switch between the plain camera image, the false-color depth image, the thermal image (when a thermal camera was used), and the 3D view (when depth was captured).
  • Timecode - each detection's metadata carries the global timecode synced to the project start time and FPS, shown in the detail view. Use it to line evidence up to the master timeline.

More detail on the review view, edit tools, and Save/export is in the Gallery help page.

6. 3D DEPTH ORBIT

This is the money shot for the edit. When a detection was captured with depth data, the gallery shows a 3D ORBIT, an orbitable point cloud of the scene at the moment of the hit.

  1. Open a detection that has depth (it will offer the 3D layer or a 3D ORBIT button).
  2. Drag to orbit the camera around the scene. It has smooth inertia, so a small flick keeps it slowly rotating, perfect for capturing a clean, cinematic move.
  3. Scroll to zoom in and out.
Capturing the orbit: start your screen recorder (see step 10), give the cloud a slow drag, and let the inertia carry the rotation while you record. You get a hands-off, steady orbit with no jitter.

If a detection only shows a still and no 3D option, that capture simply didn't include depth data. Not every detection does.

7. EVP AUDIO LAB

Audio evidence (EVP) is reviewed in the EVP Audio Lab. Open it from the gallery's EVP Studio button, or the LAB button on the EVP panel.

  • Play back captured audio with a seekable waveform.
  • Markers dropped during capture appear on the timeline so you can jump to the flagged moments.
  • Screen-record the lab while you play a clip to get the waveform moving on screen for the edit.
  • Export Snippet: drag across the waveform to select a moment, then hit EXPORT SNIPPET. You get the trimmed audio (WAV and MP3), the matching still image (or the frames just before and after if none lands exactly on the sound), a caption file to note what was heard, and an optional audiogram video with the moving waveform and audio ready to drop straight into the edit. Everything zips into one share pack.
  • The audiogram video comes in two looks: image full-frame with the waveform glowing along the bottom, or a clean split with the image on top and the waveform panel below.

8. RECORDED DETECTION CLIPS

Many detections include a short clip (an MP4 of the moment) and, for tracked subjects, a tracking video. You can play these inside the detection's review view.

To grab the raw file directly, use the reveal-in-Explorer control on the folder path (Settings, Recording), then browse into the matching session_* detection subfolder. The clip is saved as clip.mp4.

9. EVIDENCE WALL AND SENSOR-FEED RECORDINGS

The day's drop may also include full-length screen recordings of the Evidence Wall or a live sensor feed that the operator captured during the session. These are plain MP4 files in the screen-recordings part of the Specter folder.

  • Play them in any Windows video player, or drop them straight onto your NLE timeline. No SPECTER needed for these.
  • They're useful as B-roll of the live rig in action: the wall of feeds, the direction-finder radar, sensor sparklines updating in real time.

If a feed recording looks like it's missing, check the screen-recordings subfolder inside Specter and confirm you pointed the app's Screen Recording folder there (step 4) so it's easy to locate.

FILE AND FOLDER STRUCTURE REFERENCE

You never need to open these files by hand (the app reads them for you), but here is what's inside the Specter drop so you know what each piece is.

Top level

Specter\
  detections\            <- capture events, grouped by session
    session_<id>\
      session.json
      det_<id>\
        ...detection files...
  recordings\            <- full-length screen recordings (.mp4)
    evp\                 <- audio evidence, one folder per clip
      <evp-id>\
        ...evp files...

A day's drop may lay this out slightly differently (for example detections and recordings split into separate top-level folders). The names that matter are the session_* folders for the gallery and the .mp4 files for the recordings.

A session folder (session_<id>)

  • session.json - the index for that session. Lists every detection with its id, timecode, mode, and intensity. The gallery uses this to build the grid.
  • det_<id>\ - one folder per detection (see below).

A detection folder (det_<id>)

Not every detection has every file; a still-only capture won't have depth or thermal files. Common contents:

  • snapshot.png - the clean camera still.
  • snapshot_annotated.png - the same still with the on-screen detection markers baked in.
  • overlay.png - just the marker overlay, transparent background.
  • snapshot_depth.png - the false-color depth image (distance shown as color).
  • snapshot_3d.png - a pre-rendered still of the 3D view for quick preview.
  • depth_raw.bin - the raw depth data. Needed to rebuild the orbitable 3D point cloud.
  • depth_rgb.jpg - the color image aligned to the depth frame.
  • depth_intrinsics.json - the camera lens data the 3D view needs. If this is missing, the 3D orbit can't be rebuilt.
  • thermal.jpg / thermal_annotated.jpg - thermal image (only if a thermal camera was used).
  • scan.ply - a 3D point-cloud file you can also open in external 3D tools.
  • clip.mp4 - a short video clip of the moment.
  • tracking.mp4 and a tracking\ folder of frame_0000.png stills - the frame-by-frame track for a moving subject (only for tracked detections).
  • metadata.json - all the details for this detection: type, confidence, intensity class, timecode, timestamp, and sensor readings.

Keep everything in a detection folder together and unrenamed. The gallery finds these by exact name, and the 3D orbit needs depth_raw.bin plus depth_intrinsics.json side by side to rebuild.

An EVP folder (under recordings\evp\)

  • audio_raw.webm - the original captured audio.
  • audio_preview.wav - a seekable copy the lab uses for smooth playback and scrubbing.
  • markers.json - the moments flagged during capture (they appear on the lab's timeline).
  • metadata.json - details for that audio clip, including timecode.

Screen recordings

  • .mp4 files in the recordings folder - full-length captures of the operator's session, the Evidence Wall, or a live sensor feed. Play them in any video player or drop them straight onto your timeline.

10. SCREEN-CAPTURING FOR THE EDIT

To turn any of the above into footage you can cut with, screen-record SPECTER while you interact with it:

  1. Use your preferred capture tool. OBS Studio (free) or the built-in Xbox Game Bar (Win plus G) both work well on Windows.
  2. Record SPECTER full-screen for the cleanest result. Hide your mouse cursor if your tool allows.
  3. Then perform the move you want on camera:
    • Slowly orbit a 3D depth detection (step 6).
    • Flip through gallery stills and the RGB to DEPTH layer toggle.
    • Play an EVP clip with the waveform moving (step 7).
    • Play a detection clip or tracking video (step 8).
  4. Capture at your project frame rate (typically 24, 25, or 30 fps) so it drops onto the timeline clean.
Tip: the 3D orbit's inertia means one gentle drag gives you a long, smooth, steady rotation. Record a few seconds of that and you've got a reusable cinematic move without touching the mouse again.

SUGGESTED SHOTS TO CAPTURE

A repeatable checklist so every day's evidence gets grabbed the same way. Record each as a clean full-screen capture (see step 10). Aim for a few seconds of hold before and after each move so there's handle to trim.

Per standout detection

  • RGB still - the clean camera snapshot, held steady for 3 to 5 seconds.
  • Annotated still - the same frame with the detection markers on it (great for lower-thirds / callouts).
  • RGB to DEPTH toggle - flip the layer bar from RGB to DEPTH on the same detection so the reveal reads as one move.
  • 3D orbit - one slow drag, then let the inertia carry a smooth rotation for 6 to 10 seconds. This is the hero shot.
  • 3D orbit, slow zoom - a second pass where you scroll in gently while it rotates, for a push-in feel.
  • Detection clip - play the built-in clip.mp4 full-screen.
  • Metadata / timecode - a brief hold on the detail view showing the timecode and readings, if you want the "data" look on screen.

Gallery overview

  • Full grid - the gallery wall of thumbnails for a session, held for a few seconds.
  • Scroll pass - a slow scroll down the grid.
  • Filter in action - change the intensity or session filter on camera so the grid re-populates.

EVP audio

  • Waveform playback - play a clip in the EVP lab with the waveform moving.
  • Marker jump - click a flagged marker so the playhead jumps to the moment.

The live rig (B-roll)

  • Evidence Wall recording - the full wall of feeds in motion (from the supplied screen recording).
  • Direction-finder radar - the sensor bay radar with the needle and proximity ring moving.
  • Sensor sparklines - the traces updating in real time.
Naming tip: save each capture with the detection's timecode or session id in the filename (for example s03_TC01-14-22_orbit.mp4) so it lines up fast on the timeline and matches the metadata.
