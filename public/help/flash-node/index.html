Flash Your Node Over USB

Install or recover your SPECTER Node firmware directly from this page. No Arduino IDE, no libraries, no wireless update needed. Plug the node into your computer with a USB cable and click Install.

When to use this: use the USB flasher if wireless updates will not install, if the node is stuck after a bad update, or to set up a brand new board for the first time. Once you are on the latest firmware, future updates install wirelessly from the node's Settings page.

How to flash

1
Connect the node to your computer with a data USB cable (a charge-only cable will not work).
2
Click Install / Recover Firmware above.
3
In the popup, pick the serial port for the node. It usually shows as CP2102, CH340, or USB Serial. If nothing appears, install the USB-to-serial driver for your board and reconnect.
4
Choose Install and let it run. It erases and writes the full firmware, then the node reboots into the SPECTER portal.
5
Reconnect to the node's Wi-Fi portal and re-enter your network details. A full USB recovery may reset LED and threshold settings to defaults.
Board will not enter flashing mode? Hold the BOOT button on the ESP32 while you click Install, and release it once flashing starts. Some boards need this to accept a new image.
"Failed to write compressed data" during flashing? This is a USB transfer interruption, not a firmware setting error. Close the SPECTER app and any serial monitor, disconnect the LED ring VCC temporarily to reduce USB power draw, use a short data cable directly into the computer, then reconnect and retry. Hold BOOT, tap EN / RESET, keep holding BOOT until the installer begins writing, then release it. After the flash completes, reconnect the LED ring power.
