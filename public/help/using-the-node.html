USING THE SPECTER NODE IN THE APP

Pair the wireless field sensor, read its telemetry, and let it trigger evidence captures

The SPECTER Node is a small wireless field sensor with a magnetometer and a proximity antenna. Once it is on your network it appears inside SPECTER on its own rail widget, streams live telemetry, and can fire an evidence capture on its own. This page covers using a node you already have. To build one, see Build Your Own SPECTER Node.

PAIRING

SPECTER hosts the connection and the node finds it automatically. There is nothing to type in.

  1. Power the node on the same Wi-Fi network as the SPECTER computer.
  2. SPECTER broadcasts a discovery beacon on the network. The node hears it and connects back.
  3. Within a few seconds the node appears in the node rail widget with a live connection dot.

RAIL WIDGET READOUTS

ReadoutMeaning
Magnetometer amplitudeCombined field strength. Spikes when the local magnetic field shifts.
ProximityField near the antenna. Reads a higher value as something gets closer.
ConnectionLive, or offline after a sustained loss of signal.
The node auto-baselines at boot, so it settles to the ambient field of wherever you set it down. Give it a couple of seconds after power-on before reading it.

OPERATOR ALERT THRESHOLDS

SPECTER has its own software thresholds, set in Settings > Sensors & Alerts > SPECTER Node. These are separate from the thresholds baked into the node's own onboard buzzer and LEDs. The app thresholds decide when SPECTER reacts on screen; the node's own thresholds decide when the device beeps and flashes in the field.

Live delta readouts next to each slider let you watch the current signal, so you can set a level just above the room's noise floor.

THE SNAPSHOT TRIGGER

Arm the snapshot trigger and SPECTER will capture an evidence frame automatically whenever a sensor delta crosses your app threshold. Magnetic crossings and proximity crossings are evaluated separately, each with its own short cooldown so a noisy room does not flood the gallery.

Each auto-capture lands in the gallery like any other detection, with its type, confidence, and synchronized timecode.

Pair this with the Instrument Bay on a second screen to watch the Direction Finder while the node arms your captures.
