DEPTH / 3D

SymptomLikely causeFix
"CONNECTING TO DEPTH SENSOR" overlaySensor booting or unpluggedWait 5-10 s; check USB 3.0; replug the sensor; verify the SDK/service for Kinect.
DEPTH view blackNo depth streamSelect the RealSense/Kinect source; check the performance preset isn't blocking depth.
3D view emptyIntrinsics not loadedRestart the app; confirm the sidecar/bridge is running (RealSense).
Flickering brightness/colors in live depthOld buildUpdate to the latest build (range smoothing fix). Keep RANGE near center.
Close objects white, far black (or reverse)RANGE slider off-centerReset RANGE to 50 (center).
Gallery DEPTH looks flat / wrongStatic PNG vs rawUse the DEPTH layer (re-rendered), not an old screenshot; move RANGE.
Gallery RANGE doesn't affect color depthOld buildUpdate, RANGE now affects both mono and false-color.
No 3D button in galleryOld detectionOnly detections captured after the 3D snapshot feature was added have one; capture new detections.
No D / 3D badge on a cardNo depth saved for that hitThe sensor wasn't streaming depth at detection time.
Remember: in DEPTH and DEPTH_3D, color always means distance. POINT_CLOUD is the mode that textures points from the live camera. See DEPTH & 3D controls.

SPECTER NODE

SymptomLikely causeFix
Node on Wi-Fi but app does not discover itWindows Firewall blocking inbound, or AP client isolationTemporarily disable Windows Firewall to test. If that fixes it, allow SPECTER through. If using a phone hotspot or guest network, try a non-isolated access point.
Node connects but rail panel disappearsMissed status event during a burstThe rail now self-corrects every 2 seconds. If it does not, ensure SPECTER Node is enabled in Settings and restart the app.
Node over-triggers after a syncStale baseline under new thresholdsThe receiver recalibrates automatically after sync. Keep clear of the nodes for ~10 seconds. If it persists, run REBASELINE from the app or portal.
MAG slider shows 0-4095Old app versionUpdate the app. The slider is now 0-100 to match the firmware. Any stored value above 100 resets to 70.
AUDIBLE ALERT does not mute a nodeNode firmware below 2.15.0Update the node firmware via OTA or USB flash.
Direction finder arrow points wrong wayDisplay orientation not calibratedRun orientation calibration: hold a magnet at FRONT and press FRONT, add other directions. See orientation calibration.
Node trace column is blankPanel height too small or no data yetWait a few seconds for data. If still blank, widen the dock or reduce the number of visible panels.
Node will not join Wi-Fi after reflashStale SDK WiFi NVSOpen the node portal, re-save your Wi-Fi credentials. This clears the stale connection state.
Node loses connection intermittentlyWeak Wi-Fi or relay hop degradingCheck route quality in Settings. If relayed, move the gateway node closer or add a direct path. Run Relay Assist diagnostics.
Nodes behave inconsistently (one over-triggers, another is sluggish)Hand-wiring or antenna-length differences between nodesRun CAPTURE ALL (2 MIN) in Settings (Sensors & Alerts) to capture all nodes simultaneously. The summary flags which node has higher baseline noise, RC fault rate, or worse RSSI. Adjust thresholds per node or inspect the flagged node's wiring.
Node proximity trace flickers or jumps on its ownEMI spikes from nearby electronicsFirmware 2.15.1+ applies a median-of-3 de-glitch filter to the theremin display and span auto-fit. Update the node firmware if on an older version. Check the per-node diagnostic log to confirm EMI spikes in the raw data.
Node portal freezes or telemetry stutters every few secondsBlocking TCP connect to a stale saved app IPOpen the node portal and re-save Wi-Fi credentials to clear the stale connection state. Check /diag/stalls in the portal for loop-blocking events. See diagnostic log reference.
REBASELINE ALL or IDENTIFY ALL does not reach a nodeNode not in connected state or relay-assist virtualCheck that the node shows a green connection dot in the rail. Relay-assist forwarded nodes may not respond to broadcast commands. Move the node to direct Wi-Fi range or rebaseline from its own portal.
